- **Basin-of-attraction overlay refinement (first-paper scope).** Implemented as a single-panel wheel overlay (see the **Implemented** sub-item below); this entry now tracks remaining refinement. Findings + derivation in [theory/basins_of_attraction.md](theory/basins_of_attraction.md); code-editing gotchas in [.claude/rules/basin-estimation.md](.claude/rules/basin-estimation.md). The original target was two panels — **Left:** dense `(x,y)` stable-count colormap; **Right:** a sparser mesh of allocentric arrows, each encoding the *robustness* (basin width) of a stable direction — but the wheels encode the count, so it shipped as one panel.
  - **Basin protocol (timescale-separated, γ noiseless).** Pin the observer at `(x,y)` and sweep heading θ. For each θ, seed γ at a **fixed neutral state** (neural arg = 0 ⇒ consensus straight ahead / heading-aligned; R a small constant in the *indecision* range, ~0.1–0.2 — see resolved sub-item), run the *slaved* flow (`run_dgamma_dt` warm-started each θ-step, then `dθ = K·R·sin(arg(γ)/2)`) to steady state, and record which stable SC eq it reaches. The basin of a stable eq is the **arc of θ that flows to it**; its width is the robustness scalar. Boundaries are found by **destination-flip bisection** (`NBM._basin_destination` / `basin_arcs_at_focal_loc`), seeded *neutrally* rather than from the committed γ, which makes the boundary single-valued (removes the history-dependence; see [theory/basins_of_attraction.md](theory/basins_of_attraction.md) §7). 1-stable cells: basin = whole circle ⇒ max-robustness arrow, no sweep needed.
  - **Seed R — RESOLVED:** a small constant in the *indecision* range (~0.1–0.2): below the committed `R ≳ 0.4` seen in walker sims (so it represents a genuinely uncommitted observer), above the `R ≈ 0` point where arg(γ) is degenerate. With `arg(γ)=0` fixed, R is the *only* knob that can pick between coexisting γ-branches at a fold (a single threshold along the positive-real ray), and it bites only in those thin wedges — sensitivity-check that 0.1 vs 0.2 (vs ~0.3) moves boundaries only there.
  - **Open sub-decisions:** (a) robustness encoding — arrow length vs color. (b) Adaptive arrow placement so the (sparse) mesh is guaranteed to sample every distinct region of the left-panel count map (esp. multistable cells and count-boundary cells).

- **Commitment characterization in multistable basins (research; tool: `NBM.basin_arcs_at_focal_loc`, comparing neutral R≈0.15 vs committed R≈1 seed via its `R_seed` arg).** With `arg(γ)=0` fixed, the seed R is the only knob that selects between coexisting γ-branches at a fold, so comparing an uncommitted (R≈0.15) vs committed (R≈1) seed map isolates the *commitment-sensitive wedge* and which destination "requires commitment" (i.e. is only reached from the high-R warm-start). Initial 2-target finding at (4.0,1.5): commitment is required to hold the *farther / weaker-perception* target; an uncommitted walker defaults to the closer/stronger one; the wedge is thin (~4% of headings); the two SC-eq R's are nearly equal, so *perception strength* — not equilibrium R — is the discriminator there ([theory/basins_of_attraction.md](theory/basins_of_attraction.md) §9). Open questions: (a) does this generalize where the **γ-fold spans a wide angular range**; (b) the **consensus-equilibrium-vs-single-target** case, especially the **three-target (locust)** geometry — does the center target pull walkers off the second decision point, and would a lower-R (less-committed) γ warm-start change that outcome?
